# ConectaTalentos
SOBRE O PROJETO
Nossa plataforma foi criada com o intuito de conectar jovens à oportunidades de aprendizado e emprego, oferecendo cursos profissionalizantes e direcionamento à vagas no mercado de trabalho.
A proposta é oferecer um ambiente simples, acessível e intuitivo, onde os usuários possam encontrar cursos para desenvolver novas habilidades e ter acesso a oportunidades de emprego.
OBJETIVO
Nosso principal objetivo é contribuir para a formação e empregabilidade de jovens, facilitando o acesso à educação e às oportunidades profissionais.
A plataforma busca: 
Incentivar a capacitação profissional;
Facilitar o acesso a cursos educacionais;
Ajudar jovens a encontrar oportunidades de emprego;
Aproximar jovens de empresas e oportunidades de mercado.
TECNOLOGIAS UTILIZADAS
HTML5 - Estrutura e organização das páginas;
CSS3 - Estilização, layout e responsividade;
Figma - Prototipação e criação das interfaces;
Git e GitHub - Versionamento e gerenciamento do código.
Design e Prototipação
Antes do densevolvimento, foram criados protótipos e layouts para definir a estrutura visual e a experiência de navegação da plataforma.
O design foi pensado para proporcionar uma experiência:
Simples;
Intuitiva;
Moderna;
Acessível;
Responsiva.
